# Wallet Studio 0.5.4

Una recuperación de un iPhone desconectado bloqueaba las transferencias a cualquier otro iPhone, aunque este tuviera una copia original verificada. Ahora se comprueba el dispositivo de cada registro pendiente. Se conservan todos los registros y las copias; no se marca ninguna recuperación como terminada por este cambio.

Las operaciones pendientes del mismo iPhone bloquean las transferencias a todas sus tarjetas, porque comparten los archivos auxiliares de Libros. Los registros inválidos y los errores de lectura siguen bloqueando las transferencias. Sin dispositivo seleccionado, el bloqueo es conservador.

La selección de una tarjeta conserva el iPhone conectado y evita usar la copia de otro dispositivo para capturar un diseño personalizado como si fuera su original.

Se mantienen el recorte por bordes independientes y la biblioteca automática de diseños. Esta versión no incorpora animación funcional en Apple Wallet.

La copia original y los registros de recuperación son datos locales privados. No están incluidos en este paquete ni en GitHub.
