# Wallet Studio: código y diagnósticos de compilación

Repositorio público de compilación separado, publicado con autorización del propietario. Contiene el código Windows 0.5.2 con recorte y guardado automático, sus dependencias fijadas y licencias, y el diagnóstico iOS sintético v11. No incluye ejecutables existentes, copias bancarias, estado personal, diseños personales, conversaciones ni reportes de teléfono.

La compilación Windows 0.5.2 y sus pruebas se ejecutan mediante el workflow Windows checks. Los ZIP portables estarán en los artefactos de las ejecuciones correctas. Hasta que termine una ejecución correcta, este código no representa un binario validado.

La animación en Wallet sigue sin demostrarse. Los diagnósticos iOS acceden exclusivamente a objetos sintéticos y al directorio de su propia aplicación.
