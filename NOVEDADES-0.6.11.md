# Wallet Studio 0.6.11 para Windows

Nueva interfaz nativa de cristal oscuro: luces cian/violeta, paneles translúcidos en capas, navegación con iconos, controles degradados y barra de acciones. Biblioteca muestra el catálogo y una vista seleccionada lateral cuando hay espacio; las ventanas pequeñas conservan la composición apilada.

Es la aplicación Windows de Wallet Studio, con las funciones de cuenta, compra, dispositivos, tarjetas, copias, recuperación, biblioteca y nube de 0.6.10. No es el prototipo web ni utiliza sus cuentas o acciones simuladas. El efecto cristal se pinta en egui y no implica desenfoque del escritorio de Windows.

Se conservan los originales, las comprobaciones previas a transferir y el flujo de diseños a resolución original. Este cambio de interfaz no publica diseños, no cambia el servidor y no certifica todavía un resultado físico en el teléfono.
